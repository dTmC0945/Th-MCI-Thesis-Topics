Chapter 4  

Thesis Guidelines

Once you have begun working with on a topic, it is always a great idea to understand what is required of you in terms of fonts, style, and the content. This chapter will give an overview of how the thesis is supervised from the authors perspective.

Please have a look at this section prior to attending initial discussions on thesis.

The goal here is not to burden you with additional workload, but to provide a consistent framework for you to successfully attain your degree.

To write a thesis which conforms to the guidelines set by MCI, a LaTeX standard was written, called mcidoc which its source file can be accessed in its GitHub Repo.

There are two (2) branches.

You need to use the main branch if you are downloading the source file as the develop branch can contain unstable code.

To access its documentation you can have a look at it here.

If you need a good-ish documentation on how to use LaTeX, please have a look at the lecture repo L-MCI-BSc-Academic-Writing which contains material for starting to work with LaTeX and also gives useful tips & tricks on how to use it efficiently.
