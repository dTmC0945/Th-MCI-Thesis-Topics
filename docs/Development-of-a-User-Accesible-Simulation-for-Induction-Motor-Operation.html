2.1 Development of a User Accesible Simulation for Induction Motor Operation ¶

This project will involve the dynamic modelling of a polyphase (3 phase or 6 phase) induction motor using a programming language (MATLAB or Python). In addition, you will have a chance to learn different control techniques that are developed and are currently in use for the induction/asynchronous machine.

Objectives

  1. Learn the operating principle of an induction/asynchronous machine,
  2. Learn the use of reference frames for induction/asynchronous machine modelling,
  3. Learn how to simulate an electric machine in a virtual environment,
  4. Produce a simulation to showcase dynamic behaviour of the induction/asynchronous machine,
  5. Learning the control techniques and their principle of operation,
  6. Simulating a control technique of your choice in your induction/asynchronous machine (optional).

Outcomes

  1. Understand how to model an electrical machine,
  2. Understand how an induction/asynchronous machine is studied and operated,
  3. Learn different types of control techniques for an induction/asynchronous machines.
