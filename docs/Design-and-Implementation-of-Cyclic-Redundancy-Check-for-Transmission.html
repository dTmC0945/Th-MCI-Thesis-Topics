2.2 Design and Implementation of Cyclic Redundancy Check for Transmission ¶

A cyclic redundancy check (CRC) is an error-detecting code used in digital communication networks and storage systems to detect accidental changes to raw data. Blocks of data that are transmitted get a short check value attached to the block code, based on the remainder of a polynomial division of their contents. When retrieved, the calculation is redone and, in the event the check values do not match (i.e., when an error occurs during transmission), an action can be taken against data corruption.

This project will involve an experimental design of a communication system involving two Arduinos. These two Arduinos will communicate with each other and check each transmitted message using CRCs.
